# Minimal RinkLink scope

The current branch implements team matching and scheduling. Its contract and startup instructions are in the root README.

Future work should improve these retained workflows: matching explanations, venue/postcode data quality, calendar interoperability, proposal reminders and schedule imports. Player operations, league administration and arena inventory are outside this application's scope.

Do not treat the preserved full-app migration history as the active schema. Do not deploy this branch onto the full-app service or database.
